# BiliCacheExporter 桌面介面與可攜發行改版

Status: ready-for-agent

Resolution: resolved

日期：2026-10-26（Asia/Taipei）

本規格由本次討論與使用者最終選定的「精簡清單」原型整理。使用者已確認技術選型、連線與下載方式、外觀方向，以及「假手機反覆測試＋真實影音工具＋交付前真手機」的驗證方式。本規格只發布需求，不代表已開始或完成移植。

## Problem Statement

現有 Windows 工具已完成本機核心驗收，但自含式發行資料夾散落大量 DLL，介面看起來像工程樣品，且待機時每五秒執行一次裝置列表查詢。使用者希望得到資料夾乾淨、現代且簡潔、由自己控制連線的桌面工具。

使用者較熟悉網頁開發，有 Vue 2 經驗，希望未來能理解及參與介面維護，也希望未來移植到其他桌面平台時能重用成果。跨平台是技術選型的加分項，這次仍以 Windows 為交付目標。

改版必須保留原有國際版快取掃描與安全匯出能力，不能以換語言或美化為由刪掉多畫質、完整影音驗證、部分完成、取消、不覆寫與唯讀保護。

## Solution

以 Tauri、Vue 3、TypeScript 與 Rust 取代 WinForms／C# 應用程式。使用者最終選定「精簡清單」：頂部是裝置連線，中央是可勾選影片清單，底部是輸出位置、匯出操作與進度；設定另頁，詳細記錄收合。預設深色搭配藍色主色，提供完整的淺色模式切換並保存選擇。

Windows 發行以一個應用程式 EXE 為入口，不在程式旁散落框架 DLL。容許設定 JSON／config、log 資料夾，以及必要的 ADB／FFmpeg 相關檔案。缺少工具時引導使用者下載到程式旁的 tools 資料夾，亦可手動指定既有工具。完成必要環境與工具設定後，可離線使用核心功能。

程式開啟後等待使用者按「連線」，不自動列舉裝置或持續輪巡。連線成功後自動掃描；重新掃描與匯出前檢查所選裝置。Windows 依賴 WebView2，缺少時提供明確的安裝引導。

## Implementation Decisions

- 技術選型已確定為 Tauri、Vue 3、TypeScript 與 Rust。Vue 負責介面與呈現狀態；Rust 負責裝置、快取解析、外部工具、下載、設定、儲存與匯出協調。最終交付不依賴另啟 C# 核心程序，也不要求安裝 .NET。
- Windows 桌面優先；以可重用的介面及 Rust 核心保留未來移植空間，不建立尚無需求的跨平台抽象。其他平台仍需處理工具、平台整合與打包驗證，不能宣稱只重新編譯即可完成。
- 主要應用邊界為使用者可觸發的連線、掃描、匯出、取消、工具設定與設定保存等命令，以及其結果／進度通知。只提供目前流程所需的資料與操作；前端不可自行拼接任意 shell 命令或任意執行程式。
- Rust 移植沿用現有裝置存取、快取解析、子程序執行、批次匯出與安全儲存等責任。以既有可觀察行為為依據，不照搬 WinForms 的控制項結構，也不順便擴充格式。
- 最終選定的是原始原型的「精簡清單」。分欄工作台、其減壓修訂與封面書庫均不是此次交付方向。頂部放裝置連線，中央放影片清單，底部放輸出位置、匯出按鈕與進度；設定另頁、詳細記錄可收合。
- 預設深色、藍色主色，提供淺色切換並保存選擇。兩種模式均涵蓋清單、畫質選單、停用控制、提示、錯誤、對話框與進度，不加入自訂主色或多套換膚系統。
- 原型是視覺與操作參考，不是完整功能規格。原型中預先勾選兩片、虛構作者／時長、假封面文字、固定下載大小、假路徑、假進度、情境切換列與模擬按鈕行為不得直接成為正式行為。正式清單初始不勾選；只呈現實際取得的中繼資料，不猜造資訊。
- 啟動後不自動查詢 ADB，也不設背景計時器或常駐裝置監視。按「連線」才做一次裝置發現與狀態檢查；單一已授權裝置可直接連線並掃描，多裝置先讓使用者明確選定，不自動選錯手機。沒有裝置時仍可透過連線按鈕重查。
- 連線成功自動掃描，保留手動重新掃描。重新掃描與匯出前確認選定裝置及授權狀態；切換裝置使舊清單失效。插拔與授權狀態不要求即時反映；作業期間仍須處理真實工具回報的斷線、逾時與失敗，不因操作前檢查通過就忽略後續故障。重新連線不自動恢復匯出。
- 工具缺少時，在需要相關功能時列出缺少項目、固定且驗證過的版本、可信來源、實際下載大小及「下載並設定」操作。下載到程式旁的工具資料夾，保存可攜相對位置；不能用原型示意大小取代正式資訊。
- 不在每次啟動時查更新，也不追逐遠端最新版本。下載使用 HTTPS 並依隨應用版本發行的可信 SHA-256 核對；先下載到暫存，檢查完整性、必要檔案與可執行性後才啟用，不以半成品取代已可用工具。解壓只能落在工具暫存範圍，拒絕路徑穿越。失敗與取消可恢復操作、重試或改指定工具。
- 工具來源與具體版本由實作時依 Windows 架構、所需功能、來源可用性及再散布條件選定並記錄，不在此規格虛構已完成選擇。ADB 的必要 DLL 等支援檔可以保留在工具資料夾；FFmpeg 與 FFprobe 必須成套可用。保留手動工具位置設定與驗證，未加入 PATH 亦可使用。
- Windows 發行以單一應用程式 EXE 為主，前端資源隨應用程式封裝；設定檔、日誌資料夾與工具依賴允許存在，不在程式根目錄散落框架 DLL。容許正常系統暫存／執行環境快取；不要求每個執行階段在整台電腦上都只有一個檔案。
- 接受 Windows WebView2 執行環境依賴。缺少時提供清楚的安裝引導；不能依賴尚未啟動成功的網頁畫面才顯示該引導。完成 WebView2 與工具設定後，核心操作不得依賴遠端網頁、CDN 或網路服務。
- 設定與日誌保留在可攜資料夾，日誌整理到 log 資料夾，不靜默改存使用者資料目錄。保留舊版工具、輸出、暫存等有效設定並加入主題選擇；設定升級不破壞原檔或默默丟棄使用者值，舊日誌不刪除。不可寫或設定損壞時提供可操作的提示。
- 原版國際版掃描範圍與安全原則繼續適用：裝置操作綁定序號，套件查詢限定 Android user 0，手機來源唯讀；每個分 P／集數一列，動態識別品質目錄；可選畫質中繼資料缺失時降級顯示，不錯誤封鎖完整影音。
- 初始無選取、單畫質自動指定、多畫質須明確選定；無效項目可見但不可勾選，全選僅涵蓋可匯出項目。沒有可匯出選取時停用匯出；作業中避免重疊連線、掃描或啟動第二批匯出，仍保留取消能力。
- 保留只傳輸選取影音、輸出／暫存可寫與空間檢查、stream copy、原圖封面內嵌、正片與 attached picture 分辨、完整影音解碼、封面驗證、不覆寫落檔、Unicode 檔名、取消終止子程序、單項失敗繼續、手動重試與安全暫存清理。有效影音但缺封面標示部分完成，不能回報全部成功。
- 日誌不自動上傳；沿用遮蔽敏感資料的原則，原始工具輸出供解析，只有寫入日誌時才遮蔽，不能先遮蔽而破壞解析。安全處理不可信遠端路徑、檔名與外部程序引數。延續執行版本／來源識別能力與必要提交檢查，不為遷移略過品質檢查。

## Testing Decisions

使用者已以白話方案確認：平常用假手機反覆測試成功與故障，產出的影片用真實工具檢查；交付前用真手機確認完整流程。以下是待實作的驗證計畫，不表示新版本已通過。

- 好的測試驗證清單、選取、進度與錯誤、輸出內容、保存設定、取消結果、來源唯讀及不覆寫等外部行為。不鎖死 Rust 類別／模組切法、Vue 元件樹或 CSS 細節。
- 主要測試入口集中在應用層命令與結果：由連線／掃描到匯出與取消，不替每個內部函式建立測試介面。延用既有外部工具執行邊界的做法，模擬 ADB 回應與傳輸；影音處理使用真實 FFmpeg／FFprobe，驗證產出的 MP4、完整解碼與嵌入原始封面。
- 工具下載新增可控的下載來源替換點，限於下載這個真實外部依賴；同樣從工具設定的應用層操作檢查結果。覆蓋正確與錯誤雜湊、中斷、取消、解壓越界、必要檔案缺失、不可執行、不可寫、重試，以及舊有可用工具未被失敗下載破壞。自動化不依賴公開網站當時是否在線。
- 既有先例是 assert 式自我檢查與掃描、匯出、封面、畫質、批次、儲存、可攜診斷流程測試；已有 ADB 替身搭配真實影音工具的案例。移植這些案例的輸入、期待行為與樣本，而不是把 C# 測試或 WinForms 控制項檢查直接視為 Rust／Vue 已通過。
- 保留回歸案例：多裝置、未授權、離線、未知／不完整／缺檔快取、損壞與可選中繼資料、動態品質目錄、正片與封面辨識、來源變動、工具缺失／失敗／逾時、空間不足、路徑不可寫、特殊檔名、同名落檔、部分完成、取消、重試與異常關閉暫存清理。檢查未選影音不傳輸、手機不寫入、既有輸出不覆寫。
- 無輪巡是這次明確要求，需有針對性檢查：應用啟動及閒置期間不觸發裝置列舉；按連線才查詢，成功後掃描，按重新掃描或匯出前再檢查。驗證插拔不需即時刷新，下一次操作會顯示正確錯誤；驗證作業中斷線也不誤報完成。不以不相關的精確程序呼叫總數固定內部實作。
- 少量介面流程檢查精簡清單的裝置選擇、初始不勾選、多畫質選擇、無效項目停用、批次與取消、設定返回、詳細記錄、工具設定錯誤，以及深／淺色切換與重啟保存。視覺確認涵蓋實際 Windows 視窗大小、DPI、文字對比、鍵盤與長標題，不以模擬原型檢查取代正式介面驗收。
- 可攜包檢查：只有一個應用程式 EXE，不散落框架 DLL；工具依賴整理在工具範圍。驗證缺少工具時的引導、手動指定、下載完成後離線操作、搬移資料夾後內建工具仍可找到，以及不可寫位置提示。另驗證有／無 WebView2 的處理，不宣稱開發電腦啟動就代表缺少執行環境的情境通過。
- 真手機驗收使用使用者的 Samsung 與國際版快取，重新執行手動連線、掃描、分 P／畫質選擇、匯出、完整解碼與封面檢查；播放、封面與檔案總管縮圖由使用者確認。不因舊 C# 版本已驗收就跳過 Rust 新版本驗收，也不在本規格階段自動啟動硬體操作。
- 啟動時間仍只計 EXE 啟動到主視窗可操作，不含連線與掃描。記錄新版可攜包大小、工具下載與落地大小，以及閒置時應用與 WebView 子程序的記憶體範圍；與舊版比較時說明量測範圍差異，不承諾未量測的速度或體積門檻。

## Out of Scope

- macOS、Linux 或行動平台的正式發行與驗收；本次只保留未來移植空間。
- 保留 WinForms 為最終介面、改用 Avalonia、以外部 C# 程序作為正式核心，以及交付多套可選 UI 框架。
- 分欄工作台、封面書庫、自訂主色、多套換膚、未經需求確認的動畫、帳號系統或自動更新系統。
- 背景 ADB 輪巡、即時插拔／授權監測、背景自動掃描與重新連線後自動續跑匯出。
- 每次開啟時自動查詢或更新必要工具；首次設定完全不需網路且不提供既有工具的承諾。
- 將工具實體檔案永久消除、整台電腦完全無暫存／快取，或保證 EXE 更小、啟動更快。
- Bilibili 大陸版、新快取格式支援、網路影片下載、帳號登入、私有 API、Root、修改手機快取與 DRM 規避。
- 影音轉碼、未知檔案自動修補、封面加工／獨立封面輸出、字幕／彈幕、斷點續傳、跨啟動恢復佇列與無限自動重試。
- 將原型示意資料、情境測試列與假進度交付為正式功能；原型直接升格為正式產品程式碼。
- 發布遠端議題、建立 PR、對外發布成品或刪除既有 C# 版本／歷史驗收資料。
