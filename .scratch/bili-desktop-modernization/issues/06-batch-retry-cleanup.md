# 06: 批次匯出、取消與重試

Status: ready-for-agent

Resolution: resolved

**What to build:** 多選後逐部匯出並顯示每片及整體結果；單項失敗繼續下一項，使用者可安全取消與手動重試，異常關閉後也能安全回收本工具暫存。

**Blocked by:** 04 — 單部影片安全匯出。

規格：[桌面介面與可攜發行改版](../spec.md)。

- [x] 一次逐部匯出，顯示本片階段及以項目數計算的整體進度；成功、部分完成、失敗與取消可分辨，不以完成佇列冒充所有影片皆成功。
- [x] 單片失敗後繼續後續項目；作業中避免修改已鎖定來源或啟動重疊作業，不自動無限重試。
- [x] 取消停止目前子程序與後續佇列，保留先前成功輸出，清理本次未完成產物與暫存，不觸碰手機來源或其他檔案。
- [x] 使用者可手動重試失敗、取消與部分完成項目；重試重新檢查裝置並重新傳輸，不依賴可疑殘留暫存，不覆寫先前有效影片，也不在重新連線時自動續跑。
- [x] 異常關閉後下次啟動提示清理，只清理有可靠歸屬證據的專用暫存；不掃刪輸出資料夾或使用者其他資料。
- [x] 操作完成、取消、失敗及重試後介面狀態可繼續使用，結果與錯誤可在收合記錄中查閱，兩種主題下皆可讀。
- [x] 以假手機與真實影音工具，從批次操作驗證單項失敗續跑、取消停止後續、已完成影片保留、部分完成重試、同名與異常暫存清理；05 接入後整合驗證封面結果，不把 05 列為本票開始前必要依賴。不需要真手機。
