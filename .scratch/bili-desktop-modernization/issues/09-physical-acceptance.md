# 09: 真手機與使用者驗收

Status: ready-for-agent

Resolution: open

**What to build:** 使用正式新版與使用者的 Samsung 真手機驗收完整流程，確認實際快取可安全匯出，由使用者檢查播放、封面及檔案總管縮圖，留下對應新版成品的證據。

**Blocked by:** 08 — Windows 可攜包與整合驗證。

規格：[桌面介面與可攜發行改版](../spec.md)。

- [ ] 等使用者方便接手機並授權本票驗收後才開始；重新檢查實際連線及 USB 偵錯授權，不假定舊 session 的裝置狀態仍有效。本票是唯一需要真手機的工作票。
- [ ] 在使用者本機用 08 產出的正式包，驗證手動連線後自動掃描、分 P、畫質、初始未選取、重掃及選取匯出；記錄手機、工具、程式版本與成品來源識別。
- [ ] 真實匯出樣本通過影音完整解碼及原始封面內嵌驗證；遇到封面缺失時仍須正確標示部分完成，不能為驗收修改手機快取。
- [ ] 確認來源全程唯讀、既有輸出未覆寫及所選來源對應正確；不要為了製造故障而破壞手機或有效使用者檔案。
- [ ] 播放、封面與 Windows 檔案總管縮圖由使用者親自確認；不自動啟動播放器／桌面操作，也不把自動化解碼當作使用者已確認播放。
- [ ] 真實遇到的問題回報對應工作票並修正回歸，重新驗證受影響流程；未知格式或未遇故障不能宣稱已在手機驗證。
- [ ] 記錄新版實機結果與證據，明確區分舊版歷史、本次自動化、真機及人工確認範圍；敏感資料不直接貼入公開輸出。
- [ ] 只有已驗證條件才勾選，所有必要人工項目完成才標記 resolved。手機未備妥或人工確認未完成時保持 open，不以 01–08 通過代替。
