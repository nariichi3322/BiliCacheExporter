# 08: Windows 可攜包與整合驗證

Status: ready-for-agent

Resolution: resolved

**What to build:** 產生資料夾整潔的 Windows 可攜包，處理 WebView2 首次啟動條件，讓所有新版流程在正式成品中整合可用，並提供可追溯的自動化及量測證據。本票不接真手機。

**Blocked by:** 03 — 畫質選擇與不可匯出項目；05 — 內嵌封面與完成判定；06 — 批次匯出、取消與重試；07 — 缺少工具時引導下載。

規格：[桌面介面與可攜發行改版](../spec.md)。

- [x] Windows 發行以一個應用程式 EXE 為入口，前端資源隨包；程式根目錄不散落框架 DLL，不依賴 .NET 或 C# 外部核心程序。設定、log、必要工具支援檔與正常系統暫存／快取可存在。
- [x] 有 WebView2 時正常啟動；無 WebView2 時在網頁介面不可用前也能明確引導安裝，處理取消或失敗。不藉由開發電腦已有 WebView2 就宣稱缺少環境情境已通過。
- [x] 從正式包驗證首次缺工具引導、手動指定、下載設定、搬移後工具定位、設定升級、不可寫位置及完成設定後離線運作；核心不載入遠端頁面或 CDN。
- [x] 用假手機與真實 FFmpeg／FFprobe，在正式新版串接連線、掃描、多畫質選取、單／批次匯出、封面、部分完成、取消、重試及失敗復原；無啟動／待機 ADB 查詢。
- [x] 視覺及操作驗證涵蓋精簡清單、設定頁、長標題、真封面、深／淺色、鍵盤、視窗縮放與本機 DPI；不交付原型假資料／情境控制列。
- [x] 執行版本與來源識別、診斷遮蔽及必要提交檢查在新版仍有效；具可重現建置、包內容／雜湊與檢查結果。舊 C# 成品及歷史證據不刪除，不自行對外發布。
- [x] 記錄從啟動到視窗可操作的時間，不計手機掃描；記錄成品、下載與落地工具大小，以及應用／WebView 子程序記憶體範圍。說明與歷史量測差異，不承諾未量測優勢。
- [x] 所有本票證據清楚標為假手機／本機包／環境測試；真手機、播放、封面與檔案總管縮圖尚待 09，不挪用舊版驗收作為新版已通過。
