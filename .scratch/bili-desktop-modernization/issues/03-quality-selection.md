# 03: 畫質選擇與不可匯出項目

Status: ready-for-agent

Resolution: resolved

**What to build:** 掃描後在同列選擇同一分 P 的不同畫質；清楚呈現不完整、缺檔與未知格式原因，讓選取及全選只涵蓋真正可匯出的來源。

**Blocked by:** 02 — 手動連線並掃描影片。

規格：[桌面介面與可攜發行改版](../spec.md)。

- [x] 動態辨識同一分 P 的品質候選，影音配對不靠固定目錄碼或副檔名猜測編碼；不重複展開成多列影片。
- [x] 單畫質自動指定，多畫質必須明確選擇；選擇後更新對應大小、來源、可用性與畫質資訊。後端也驗證候選屬於該項目且可用。
- [x] 初始無選取，全選與取消全選正確；未選定必要畫質及已知無效項目不能進入匯出佇列，沒有有效選取時停用匯出。
- [x] 缺檔、空檔、已知未完成、未知結構、不合法遠端路徑及不支援項目仍可見，提供不可匯出原因與唯讀盤點資訊，不嘗試解密、修補或猜測格式。
- [x] 可選畫質資訊缺失、JSON 損壞或讀取失敗時記錄並顯示實際目錄碼等降級資訊；完整影音不因此被封鎖，取消仍須向上傳遞。
- [x] 深／淺色及鍵盤操作下可完成畫質選擇並理解停用原因；正式畫面不包含原型情境切換列。
- [x] 從應用掃描／選取操作移植既有多畫質、可選中繼資料錯誤、未知與不完整樣本案例，檢查清單及可匯出結果；不需要真手機。
