# 01: 新版啟動、設定與深淺色

Status: ready-for-agent

Resolution: open

**What to build:** 可啟動的 Tauri／Vue 3／TypeScript／Rust 桌面應用，呈現使用者選定的精簡清單布局，能保存主題、手動工具路徑與輸出／暫存設定。與舊版並存，後續票逐步接入真實功能，不要求先重構舊 C#。

**Blocked by:** None (can start immediately).

規格：[桌面介面與可攜發行改版](../spec.md)。

- [ ] Windows 可啟動新版；介面為頂部連線、中央空清單、底部輸出／匯出，設定另頁、記錄可收合。沒有裝置資料時不展示原型假資料；未實作操作不假裝成功。
- [ ] 預設深色與藍色主色；淺色模式涵蓋所有目前可見控制項，切換後重啟保留。鍵盤與窄視窗下設定及返回可用。
- [ ] 從介面指定與保存 ADB、FFmpeg／FFprobe、輸出與暫存位置，透過 Rust 驗證工具可啟動；不依賴 PATH，缺少或錯誤工具有可操作提示。
- [ ] 設定留在可攜資料夾；讀取舊版有效設定，不破壞原檔、不默默丟棄值；損壞設定與不可寫位置清楚報錯，不靜默改到其他位置。
- [ ] 建立後續操作所需的最少應用命令及可替換外部工具執行邊界；使用結構化引數，不向前端暴露任意 shell 執行能力。解析保留原始輸出，日誌寫入時才遮蔽敏感資料。
- [ ] 使用者可查看基本診斷記錄，記錄留在 log 資料夾，不刪舊日誌、不自動上傳；遮蔽裝置序號、URL 查詢參數及個人路徑。
- [ ] 新版與既有版本各自可建置，不刪除舊來源、歷史驗收或發行成品；提供可重現開發指令，新增必要的型別／建置／測試檢查，不繞過既有提交檢查。
- [ ] 以應用操作驗證設定升級、保存重啟、工具錯誤及日誌遮蔽；不需要真手機，啟動與待機不觸發裝置查詢。
