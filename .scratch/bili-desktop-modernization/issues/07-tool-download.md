# 07: 缺少工具時引導下載

Status: ready-for-agent

Resolution: open

**What to build:** 缺少必要工具時，使用者可看清楚下載項目並按下載設定，成功驗證後直接使用；網路失敗時可取消、重試或手動指定已有工具。

**Blocked by:** 01 — 新版啟動、設定與深淺色。

規格：[桌面介面與可攜發行改版](../spec.md)。

- [ ] 選定並記錄可信 Windows 工具來源、固定版本、架構、實際大小、必要支援檔與再散布／授權資訊；涵蓋 ADB 及 FFmpeg／FFprobe，不使用原型假大小或浮動最新版。
- [ ] 在相關功能需要且缺少工具時引導，列出缺少項目、版本、來源、大小與下載按鈕；正常啟動不自動查更新，使用者未觸發時不自行下載。
- [ ] 下載經 HTTPS 到專用暫存，使用隨應用版本發行的可信 SHA-256 檢查；解壓拒絕越界路徑，驗證必要檔案完整及工具可執行後才啟用。
- [ ] 工具集中存於程式旁工具資料夾，內建工具位置採可攜方式保存，搬移後仍可找到；ADB 必要 DLL 不散落程式根目錄。完成設定後無網路仍能使用工具。
- [ ] 顯示可取得的下載／驗證進度並可取消；中斷、錯誤雜湊、磁碟滿、不可寫、缺檔與啟動失敗有明確提示及重試／手動指定入口，不毀損已可用工具。
- [ ] 手動設定與下載共用工具可用性驗證及結果，不另建一套核心；只補必要下載替換點供可重現測試，不依賴公開網站在線才能跑測試。
- [ ] 從工具設定操作測試成功、取消、失敗重試、錯誤雜湊、解壓越界、不可寫、手動替代及舊工具保留；實際下載來源另做取得與版本驗證。全程不需要真手機。
