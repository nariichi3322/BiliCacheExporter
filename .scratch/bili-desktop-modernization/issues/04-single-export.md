# 04: 單部影片安全匯出

Status: ready-for-agent

Resolution: open

**What to build:** 從清單選一部單畫質完整影片，匯出經真實影音工具驗證的 MP4；提供實際階段、取消及安全清理，既有影片不被覆寫。此票尚無封面時只能標示部分完成，不能假報全部完成。

**Blocked by:** 02 — 手動連線並掃描影片。

規格：[桌面介面與可攜發行改版](../spec.md)。

- [ ] 前端匯出操作經 Rust 驗證所選項目、來源、裝置與授權；開始前裝置已拔除時不傳輸並要求重新連線，作業中斷線、程序失敗及逾時同樣正確處理。
- [ ] 驗證影音工具、輸出／暫存可寫與相關磁碟空間，支援不同磁碟；只拉取選中來源，確認傳輸結果，來源變動或大小不符不可誤報成功。
- [ ] 真實 FFprobe 辨識正片視訊與音訊，封面不能冒充正片；以 stream copy 合併 MP4，不轉碼、不猜測 DRM、不嘗試繞過 DRM。
- [ ] 完整解碼驗證影音；容器可讀但內容損壞不能通過。有效影音無封面時保留 MP4 並標示部分完成，05 才補足完整成功路徑。
- [ ] 安全處理 Unicode、Windows 非法字元、保留名稱及長檔名；同名加編號，最後落檔也不得覆寫既有檔案，失敗不留下冒充成品的檔案。
- [ ] 介面顯示實際階段與可量測進度，無法量測時不造百分比；作業期間禁止重疊掃描或第二次匯出，取消保持可操作。
- [ ] 使用者取消或程序錯誤時停止本次子程序，清理僅屬於本次作業的暫存，保留既有有效輸出，明確顯示取消／失敗及可查閱原因。
- [ ] 用假手機傳輸搭配真實 FFmpeg／FFprobe，從匯出操作驗證正常 MP4、損壞封包、來源變動、斷線、空間／路徑錯誤、同名與取消；檢查來源未改、未選影音未傳輸。不需要真手機。
