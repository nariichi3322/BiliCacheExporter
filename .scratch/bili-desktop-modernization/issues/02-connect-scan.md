# 02: 手動連線並掃描影片

Status: ready-for-agent

Resolution: open

**What to build:** 使用手動指定的 ADB，按連線才發現與選定手機，成功後自動唯讀掃描國際版快取，在精簡清單顯示真實影片資訊與初始未勾選項目。單畫質完整項目能成為後續匯出來源。

**Blocked by:** 01 — 新版啟動、設定與深淺色。

規格：[桌面介面與可攜發行改版](../spec.md)。

- [ ] 啟動與待機期間不查詢裝置，無背景輪巡或常駐監視。按連線才列舉；單一已授權裝置可連線並掃描，多裝置必須明確選擇。
- [ ] 沒有裝置、未授權、offline、ADB 啟動失敗與逾時有不同且可操作的提示，使用者修正後可再次連線；不自動恢復匯出。
- [ ] 操作綁定所選序號，套件查詢限定 Android user 0，只掃描國際版，驗證遠端路徑與安全引數；手機上只讀取，不寫入、修補或刪除。
- [ ] 連線成功自動掃描並呈現封面、真實標題／分 P、已取得的大小及畫質資訊；每個分 P／集數一列，不固定品質目錄名稱。不虛構作者、時長等缺少資訊。
- [ ] 初始不勾選；單一完整畫質可指定為來源；損壞中繼資料限於該項目並顯示原因，不能讓其他有效影片消失。多畫質在 03 完成前不可默選來源。
- [ ] 手動重新掃描前再次檢查裝置；切換裝置使舊清單失效，不把舊手機選取帶入新手機。操作中避免重疊連線／掃描，離線與失敗不留下可誤操作的有效狀態。
- [ ] 接入實際掃描階段／結果通知與詳細記錄，兩種主題下提示及停用狀態可讀；不複製原型假百分比。
- [ ] 使用假手機從連線操作驗證裝置錯誤、單／多裝置、空快取、Unicode、掃描中斷線、來源唯讀、無影音拉取及閒置不查詢；不需要真手機。
