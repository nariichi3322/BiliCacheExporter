# 05: 內嵌封面與完成判定

Status: ready-for-agent

Resolution: open

**What to build:** 匯出時把原始封面嵌入 MP4，驗證影音與封面後才顯示完成；若只有封面失敗，保留有效影片並以部分完成說明結果。

**Blocked by:** 04 — 單部影片安全匯出。

規格：[桌面介面與可攜發行改版](../spec.md)。

- [ ] 取得必要原始封面，以 attached picture 嵌入 MP4；不裁切、不加字，不在輸出目錄額外留下封面圖片。
- [ ] 正片與封面在選取、合併及驗證階段保持區別；只有封面加音訊不能當成有效正片。
- [ ] 原始封面內容保留，輸出能抽出對應原圖；只有影音完整解碼及封面驗證皆通過時，介面才顯示完成。
- [ ] 缺封面、封面傳輸／格式／嵌入／驗證失敗但影音有效時保留 MP4，清楚標示部分完成及原因，不刪掉有效成果或回報全部成功。
- [ ] 封面處理保持可取消與安全暫存清理；未完成輸出、同名保護與唯讀原則不因新階段失效。
- [ ] 使用自製影音與原圖、假手機傳輸及真實影音工具，從匯出結果驗證成功、部分完成、封面冒充正片、取消及抽出封面內容。播放／檔案總管縮圖由 09 真機人工驗收，不需要本票接手機。
